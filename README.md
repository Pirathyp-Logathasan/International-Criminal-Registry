# International Criminal Registry (ICR)

A web-based student project designed to explore the development of a system for searching and viewing information about 
wanted individuals.

## About the Project
**International Criminal Registry (ICR)** is a web application inspired by **INTERPOL's Red Notice search system**. 
The project focuses on creating an intuitive and user-friendly interface for searching and viewing information about wanted 
fugitives. 

The system allows users to search using different criteria, such as: 
- First Name
- Last Name
- Nationality
- Gender
- Country (Wanted by)
- Charges

**Note: The project is developed for educational purposes and does not contain real criminal data.**

## Features
- Search for registered individuals
- View individual profiles
- Explore information about different types of INTERPOL Notices, including Red, Yellow, Blue, Green, Black, Orange, and       Purple Notices
- Read about the purpose and meaning of each INTERPOL Notice type

## Technologies 
The project is currently developed using:

- JavaScript

This project is created for **educational purposes only**. It is a fictional system and is not affiliated with, endorsed by, or connected to **INTERPOL** or any other law-enforcement organization. All data used in the project is fictional.
